## Behaviors and risks excluded from the seven-bug count

- **Balance unfinished hold reset:** actual-hook evidence shows 1,000 ms accrued becoming 100 ms after pause/resume/relock. This is a confirmed behavior, but its defect classification depends on whether the exercise requires an uninterrupted hold. Define fixed-goal and personal-best rules, then either preserve accrued work without adding paused time or clearly label Restart note. Do not confuse this with G1's definite duplicate-result corruption.
- **Native routine background ordering:** if authoritative Capacitor pause arrives before WebKit visibility becomes hidden, the App routine subscriber ignores it, while its later native visibility handler also skips it. The controlled ordering counted a synthetic ten minutes away. Actual iOS ordering/frequency was not observed. Validate both orderings on a phone, then accept the authoritative pause without the WebKit guard. Independent drone shutdown is not claimed broken.
- **Browser reference/backing audio durability:** actual web persistence/resolver functions lose imported playback bytes across fresh module state while the item identity remains. Source explicitly defines session-only browser previews; native Filesystem storage is different. Treat this as a preview limitation unless durable browser use is part of the product promise.
- **iPad parity check drift:** the existing check expects an 8 dB tablet gate adjustment, while current source intentionally uses 18 dB. Preserve the failed test result and update its contract after confirming the intended policy. This is not evidence that the product's current 18 dB behavior is wrong.
- **Rejected Quick Record candidate:** testing the open callback alone missed the actual JSX wrapper that pauses the routine first. With that wrapper, elapsed time stayed at 30 seconds after another minute and the active step was cleared. No bug reported.

## Useful optimizations after correctness repairs

1. Cache the exercise-by-project map and score/setup snapshots per library revision, reducing repeated localStorage parsing per visible library row.
2. Give routine history an explicit archive/export and size policy that preserves access to older practice; unbounded localStorage growth increases pressure on the failures above.
3. Make interruption controls consistent: distinguish Resume from Restart note and provide reachable Pause/Quit during Balance rest/results. Decide whether rest time freezes or continues while away.
4. Release temporary Audio sources and handlers after reference-file validation succeeds, fails or times out. This is resource hygiene, not a demonstrated leak.
